---
title: Bindgen
description: Schema-derived JavaScript/native bindings
---

Bindgen generates the JavaScript/native boundary from `*.schema.zig` files.
Schemas declare conversion behavior, ownership, errors, and exposed properties.

- Schemas under `src/` use `src/bindgen/schema.zig` and may import other schemas.
  They are independent of runtime implementations.
- Zig implementations bind through `bun.bindgen.Fn` and `bun.bindgen.Class`.
  C++ implementations use generated declarations; JavaScript builtins reach
  native functions through schema-declared exports.
- Generated adapters handle the wire ABI, argument lifetimes, exception
  propagation, and result transfers. Generated files belong in the build
  directory.

Run the normalizer, IR, and compile-failure tests:

```sh
./zig build test-bindgen
```

Runtime tests live in `test/bindgen/` and `test/internal/bindgen.test.ts`.
